## Summary of Problem 

‘Your way’ Pizza Parlour has asked me to create an application for their store which allows for their customers to view their pizza menu and customise the pizza how they desire. The application will allow for customisation of size, toppings, type and their choice of an optional additional side order. Once the order is made the customer is given a bill for how much the food will cost. The application is also aimed towards the kitchen staff who can view the submitted orders accurately and clearly. A GUI is mandatory in meeting the requirement of a visual, easy to navigate, simple interface accessible for all technical abilities. 

The pizza parlour application required interactivity is event-driven interactions across 3 GUI windows (PizzaGUI, SideOrderGUI and OrderSummaryGUI). The pizza GUI triggers cart appends using the “Add to Order” button on click function and the same on the side order GUI with the window being closed in addition. The order summary reads the contents of the cart list to display the items in string format on labels by calling “get_details” on all objects. Error messages are displayed on the GUI rather than printed in the console for improved readability.

## Intended Users

The target audience of the Pizza Parlour application website is the customers of the pizza parlour. This means I must take into account the variety of technical abilities these customers will have so my design must be intuitive and easy to use. The age range will be from teenagers with high familiarity of technology to elderly with a lack of understanding of how to use GUI’s suggesting all user interaction must be limited and guided. To meet the simple and easy design for elderly needs I have chosen to use elements such as comboboxes for the pizza type to avoid invalid input such as spelling errors or not on menu items inputted. I have also chosen a spinbox for size and quantity to prevent negative and non-integer values. Moreover I used checkboxes for topping selection to prevent invalid input from entry boxes.
